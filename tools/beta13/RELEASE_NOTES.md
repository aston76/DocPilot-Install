DocPilot beta 13 intègre un index SQLite local sans logiciel supplémentaire à installer. L’ancien cache est repris automatiquement. La recherche vise uniquement les fichiers correspondant à l’empreinte déposée ; elle ne relit plus tout le dossier fournisseur. Les empreintes déjà vérifiées sont réutilisées tant que le fichier n’a pas changé. Chaque classement actualise immédiatement l’index local.

DocPilot échange automatiquement de petits index par poste dans `.docpilot-index/v1` du dossier de stockage configuré. La base SQLite reste sur le disque du PC ; aucun fichier SQLite partagé n’est ouvert sur le Synology. Les autres postes récupèrent les empreintes visibles dans ce dossier. Les correspondances venant d’un autre poste sont vérifiées sur le fichier actuel avant d’être déclarées identiques. Si le partage est inaccessible, les données locales restent utilisables et la vérification est signalée comme incomplète lorsque nécessaire.

Les notifications Windows déclenchent une réactualisation après les changements de fichiers. Un contrôle périodique sert de rattrapage. Les fichiers uniquement en ligne ne sont pas téléchargés automatiquement. Avec Synology Drive, la visibilité entre postes dépend de la synchronisation ; cette version ne garantit pas l’exclusion de deux classements simultanés sur deux postes déconnectés ni un index central immédiatement cohérent.

La mise à jour montre une fenêtre indépendante avec les étapes, une progression réelle pour le téléchargement et l’extraction, puis un résultat explicite. Après une installation réussie, la fenêtre demande OK avant de relancer DocPilot. Les étapes dont la durée est inconnue utilisent une barre d’attente. Le résultat est enregistré pour permettre à l’interface de retrouver son état après redémarrage. Un échec est affiché et permet une nouvelle tentative.

Le programme est préparé et vérifié avant remplacement ; l’ancien dossier sert de récupération si le remplacement échoue. Les documents, réglages et connexions restent dans leur dossier local séparé. Aucun document, catalogue utilisateur, index privé ni secret ne fait partie du paquet public. Le paquet vise Windows x64 ; un stockage absent, non accessible ou ambigu exige encore une correction du chemin ou des droits.
